Objective
Design and verify a synthesisable SystemVerilog module that processes 64-bit packet data on clk_net, detects specific 4-byte and 8-byte patterns at fixed offsets, and transfers the data along with a unique 8-bit buffer ID to a higher-frequency clk_host domain.

Pattern Logic: * Detect PACKET_TYPE (4 bytes) at a fixed offset.
Detect one of four programmable SYMBOL values (8 bytes) at SYMBOL_OFFSET.
CDC Considerations: Use an Asynchronous FIFO to handle the transition from clk_net to the faster clk_host.

Outputs: tx_valid, tx_data[63:0], tx_sop, tx_eop, tx_length[2:0], and tx_buffer[7:0].
State Machine: Use an FSM to track the current byte offset. Ensure the buffer value is generated and ready to be asserted precisely when tx_eop is '1' in the host domain.
